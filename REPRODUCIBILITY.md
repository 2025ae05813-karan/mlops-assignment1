# Reproducibility Guide

This project is fully reproducible from a clean environment. Every artifact
(cleaned dataset, trained model, plots, metrics) is regenerated by code — no
manual steps.

## 1. Environment setup

Using `pip` (recommended, verified):

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt
```

Or using Conda:

```bash
conda env create -f environment.yml
conda activate heart-disease-mlops
```

## 2. End-to-end pipeline

```bash
# (a) Acquire + extract raw data (reuses the local zip if present)
python scripts/download_data.py

# (b) Build the cleaned dataset -> data/processed/heart.csv
python -m src.data_loader --sites cleveland

# (c) Exploratory analysis -> report/screenshots/*.png
python -m src.eda

# (d) Train, tune, evaluate, select, and persist the best model
python -m src.train --mlflow          # drop --mlflow to skip tracking

# (e) Export the MLflow run summary -> report/experiment_tracking_summary.md
python -m src.mlflow_summary

# (f) Sample inference
python -m src.predict
```

## 3. What guarantees reproducibility

| Concern | How it is handled |
|---------|-------------------|
| **Fixed randomness** | `RANDOM_STATE = 42` used for the train/test split, CV folds, and both estimators (`src/config.py`). |
| **No data leakage** | Imputation + scaling live inside the sklearn `Pipeline`, fit only on training folds (`src/preprocess.py`). |
| **Pinned dependencies** | Exact versions in `requirements.txt` / `environment.yml`, verified to install and run on a clean venv. |
| **Deterministic schema** | Column names, feature typing, and target definition are centralized in `src/config.py`. |
| **Self-contained model** | `models/model.joblib` is the full preprocessing+model pipeline, so training and serving apply identical transforms. |
| **Documented selection** | `models/model_metadata.json` records both candidate models, their tuned params, and all metrics. |

## 5. Model artifact format

- **Format:** `joblib`-serialized scikit-learn `Pipeline` (`models/model.joblib`).
- **Why joblib:** efficient for NumPy-backed sklearn objects; keeps preprocessing
  and estimator together so there is a single reproducible serving artifact.
- **Metadata:** `models/model_metadata.json` captures the selected model, tuned
  hyperparameters, feature schema, random seed, and metrics for all candidates.
